# 🏎️ F1 Manager Setup Calculator

Uma calculadora interativa e precisa de setups para o jogo **F1 Manager**, projetada para otimizar os ajustes do carro e encontrar a combinação ideal de satisfação do piloto em poucas iterações.

---

## 🛠️ Funcionalidades

* **Sincronização com Presets de Pistas:** Carregamento automático das configurações iniciais para todos os circuitos do calendário da Fórmula 1.
* **Suporte a Dois Pilotos:** Ajustes e cálculos independentes simultâneos para o Piloto 1 e Piloto 2.
* **Algoritmo de Filtragem e Interseção:** Refinamento contínuo das combinações restantes com base no feedback fornecido pelo piloto (Ideal, Ótimo, Bom, Ruim+, Ruim-).
* **Interface Responsiva e Intuitiva:** Sliders visuais e barras de intervalo em tempo real para facilitar a leitura e o ajuste direto dentro do jogo.

---

## 🚀 Tecnologias Utilizadas

* **HTML5** — Estruturação semântica da aplicação.
* **CSS3** — Estilização moderna, responsiva e suporte ao tema escuro.
* **JavaScript (ES6+)** — Lógica de cálculo numérico, manipulação da DOM e filtragem de matrizes em tempo real.
* **JSON** — Armazenamento estruturado dos parâmetros padrão de cada pista.
